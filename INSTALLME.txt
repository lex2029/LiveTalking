LiveAvatar (LiveTalking) – clean install & запуск
================================================

Это главный файл установки. Он должен быть достаточен для нового воркера.

0) Что это такое
----------------
Сервис запускает LiveTalking (ER-NeRF) воркеры локально и стримит видео/аудио
через Daily. Внешний доступ – только через Cloudflare Tunnel к порту 8090.

1) Требования (минимум)
-----------------------
- Ubuntu 22.04 / 24.04
- NVIDIA GPU (3090/4090/5090), 24–32GB VRAM
- 64GB RAM (рекомендуется)

Проверка GPU:
  nvidia-smi

2) Системные пакеты
-------------------
sudo apt update
sudo apt install -y \
  build-essential git git-lfs python3 python3-venv \
  ffmpeg cmake ninja-build pkg-config zstd \
  libgl1 libglib2.0-0 libsm6 libxext6 libxrender1 \
  libssl-dev libffi-dev

git lfs install

Примечание:
  - Ubuntu 22.04: по умолчанию python3.10
  - Ubuntu 24.04: по умолчанию python3.12

3) Драйверы и CUDA
------------------
Нужен рабочий NVIDIA драйвер (в этой системе: Driver 580.x).
Важно: для сборки CUDA‑расширений нужна CUDA Toolkit **12.8** (nvcc 12.8),
потому что PyTorch используется cu128. Если nvcc 13.x — получите ошибку
`CUDA version mismatch` при сборке.

Установка CUDA Toolkit 12.8:
  sudo apt install -y cuda-toolkit-12-8

Проверка:
  nvidia-smi
  nvcc --version
  python - <<'PY'
import torch
print("torch CUDA:", torch.version.cuda)
PY

4) Клонирование репозитория
---------------------------
git clone <ВАШ_НОВЫЙ_РЕПОЗИТОРИЙ>
cd LiveTalking

Если в репозитории используются большие файлы (LFS):
  git lfs pull

5) Python окружение
-------------------
sudo mkdir -p /venv
python3 -m venv /venv/nerfstream
source /venv/nerfstream/bin/activate

# (опционально) symlink для IDE
ln -sfn /venv/nerfstream .venv
pip install --upgrade pip

# PyTorch (пример; выберите CUDA сборку под вашу систему)
# В этой среде используется nightly cu128:
#   pip install --pre torch torchvision --index-url https://download.pytorch.org/whl/nightly/cu128
# Если хотите стабильную – ставьте стабильную CUDA сборку PyTorch (cu121/cu124).

pip install -r requirements.txt

5.1) Сборка CUDA‑расширений (обязательно)
----------------------------------------
Экстеншены raymarching/gridencoder должны быть собраны под CUDA 12.8.

  export CUDA_HOME=/usr/local/cuda-12.8
  export PATH=/usr/local/cuda-12.8/bin:$PATH
  export LD_LIBRARY_PATH=/usr/local/cuda-12.8/lib64:$LD_LIBRARY_PATH

  python ernerf/raymarching/setup.py build_ext --inplace
  python ernerf/gridencoder/setup.py build_ext --inplace

5.2) Кэш ASR/LPIPS (нужно один раз, если OFFLINE=1)
---------------------------------------------------
В daily.env по умолчанию включён offline режим для HF. Поэтому перед первым
запуском нужно скачать модели в кэш.

  export HF_HOME=/workspace/.hf_home
  export HUGGINGFACE_HUB_CACHE=/workspace/.hf_home/hub
  export TRANSFORMERS_OFFLINE=0
  export HF_HUB_OFFLINE=0

  # ASR модель (используется по умолчанию)
  python - <<'PY'
from transformers import AutoProcessor, AutoModelForCTC
model_id = "cpierse/wav2vec2-large-xlsr-53-esperanto"
AutoProcessor.from_pretrained(model_id)
AutoModelForCTC.from_pretrained(model_id)
PY

  # LPIPS (AlexNet weights)
  python - <<'PY'
import lpips
lpips.LPIPS(net="alex")
PY

После скачивания вернуть offline флаги обратно (в daily.env):
  TRANSFORMERS_OFFLINE=1
  HF_HUB_OFFLINE=1

6) Секреты и окружение
----------------------
cp keys.example.json keys.json
cp daily.example.env daily.env

Отредактировать:
  - keys.json (OpenAI/AssemblyAI ключи)
  - daily.env (DAILY_API_KEY / DAILY_DOMAIN / тюнинг видео)

7) Модели и данные
------------------
В репозиторий должны быть включены:
  - ernerf/obama_eo_head/checkpoints/ngp.pth
  - ernerf/obama_eo_torso/checkpoints/ngp.pth
  - ernerf/data/obama (transforms_*.json, au.csv, bc.jpg)
  - data/customvideo/idle (img + audio.wav)
  - archives/obama_assets.tar.zst (gt_imgs, torso_imgs, ori_imgs, parsing, openface, aud_eo.npy, aud.wav, obama.mp4, track_params.pt)

Если есть архив, распаковать в корень репозитория:
  tar --zstd -xf archives/obama_assets.tar.zst -C .

Если файл отсутствует – сервис стартовать не будет.

Проверка:
  ./scripts/verify_assets.sh

8) Запуск
---------
Основной способ:
  /workspace/LiveTalking/scripts/autostart_liveavatar.sh

Или вручную:
  /workspace/LiveTalking/start_gateway.sh

Проверка:
  curl http://127.0.0.1:8090/health

9) Cloudflare Tunnel (опционально)
----------------------------------
Если нужен внешний доступ по домену:
  - настроить cloudflared + config.yml
  - запустить /workspace/LiveTalking/scripts/run_cloudflared_forever.sh

10) Тест
--------
Открыть:
  https://<your-domain>/dashboard.html

Если "No available worker" – подождать прогрев воркеров.
